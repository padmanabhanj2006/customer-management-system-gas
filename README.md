# Customer Management System

A web-based customer management system built using Google Apps Script and Google Sheets.

## Features

- Admin Login
- Staff Login
- Customer Entry
- Daily Collection Report
- Payment Tracking
- Staff-wise Dashboard
- Google Sheets Backend
